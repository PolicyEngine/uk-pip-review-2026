# Official figures

Official costings and forecasts used to reconcile our figures, one file each, with the source in a `source` column.

- `dwp_pip_spending_spring_2026.csv`: DWP PIP spending and caseload, Spring Forecast 2026 (England and Wales plus abroad, all ages, £m nominal). The baseline line on the cost tab.

Add on the day, once published: any DWP or HM Treasury costing in the government response, and the OBR's assessment when it is made. The review itself is not expected to publish costed parameters.
