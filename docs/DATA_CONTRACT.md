# Data contract

- **Engine and data pair.** Microcosm UK 2024-25 national build `uk-frs-calibration-attempt-20261110T204756Z-9e18f010` (SHA-256 `adb6204d0af5e08a42cccec81250ce116518687f964e31c654a17d658b3416e8`, Hugging Face dataset `policyengine/populace-uk-private`) with policyengine-uk 2.177.7 and policyengine-core 3.34.10, the versions it was built and certified on (`data_build.DATA_BUILD`). No policyengine.py release covers the pair, so simulations load policyengine-uk directly; model mode refuses another engine version or file (`pipeline.CERTIFIED_BUNDLE`). Every figure carries "build uk-frs-calibration-attempt-20261110T204756Z-9e18f010, policyengine-uk 2.177.7, not in a policyengine.py release"; PIP-specific validation is pending (#1, #4).
- **PIP awards on 9e18f010.** The build stores each person's daily living and mobility assessment points for 2024 and no award category; policyengine-uk derives each year's award from the points against that year's thresholds. A points-threshold change is therefore computable on this build (`data_limits.LIMITS_BY_BUILD`). It also stores the UC limited-capability flags (`uc_limited_capability_for_WRA`, `uc_limited_capability_for_work`), which the UC health gateway overrides from the stored values.
- **Microdata stay private.** No `.h5` file, record-level extract or weight is committed (`.gitignore`, `scripts/check_public_data.py`).
- **Columns the PIP measures read:** `pip_dl_category`, `pip_m_category`, `dla_sc_category`, `dla_m_category`, `age`, `region`, `carers_allowance_reported`, `is_disabled_for_benefits`, `is_severely_disabled_for_benefits`. `pip_dl`, `pip_m` and `uc_limited_capability_for_WRA` are formulas, not stored, so a modifier may wrap them.
- **England and Wales mask.** Every table keeps England and Wales households only (`pip_review.aggregate`). In a static run households do not interact, so this gives the figures a country test would.
- **Columns the PIP measures need but the data lack:** `pip_dl_points`, `pip_m_points`, a score per activity, a health-condition group, hospital stays, award duration and review dates, caring for someone outside the household.
- **Heavy runs.** One data-loading job or production build at a time, under `/tmp/pe-heavy.lock` with at least 14 GB free (`pip_review.heavy`). Model mode runs one simulation per process; its record-level arrays stay in a temporary directory and are never published.
